mcpkeel

Privacy

mcpkeel collects nothing about you. It has no account, no telemetry and no server of its own.

Last updated 2026-10-12. This page covers the mcpkeel command-line tool, its GitHub Action, its plugins for Claude Code and Codex, and this website.

The command-line tool

  • It runs on your machine or in your CI. It reads your MCP config and mcp.lock, and writes mcp.lock and the reports you ask for.
  • It starts the MCP servers in your config, or connects to the remote ones, to read what they tell an agent.
  • For servers started through npx, uvx, pipx or docker, it asks the npm registry, PyPI or the image's registry which release will run. --no-resolve turns this off.
  • Only with --explain, it sends the changed tool definitions, and nothing else, to the review endpoint you choose, with the key you provide. Your config, environment values and headers are never sent.
  • It does not send anything to the mcpkeel project.

The GitHub Action

  • It runs the same tool inside your own workflow, on GitHub's runners or yours. What it reads, writes and contacts is the same as above, plus the job summary and the pull requests it opens in your repository.

The plugins for Claude Code and Codex

  • They run the same tool on your machine when a session starts, and keep one small record per project, with each server's name, status and change codes, in the plugin's data directory on your machine.
  • They do not use the model review and send nothing beyond what the tool itself contacts.

This website

  • It has no cookies, no analytics and no third-party scripts or fonts. It is served by Cloudflare, which processes requests to deliver it, as any host does.
